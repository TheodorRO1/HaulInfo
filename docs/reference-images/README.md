# Android Auto Visual References

This directory indexes visual reference images of Android Auto. No images are stored in this repository.

## Collection policy

- Only genuine Android Auto screenshots and official Google images are indexed.
- Images are linked from publicly accessible pages and publications. No images are copied or redistributed without appropriate permission.
- For each reference: descriptive name, what it demonstrates, original source URL, publication/documentation date, feature/version where known, and release status.
- No proprietary application assets, source code, or extracted resources are copied.
- No artificial screenshots are created and presented as genuine Android Auto references.
- No promotional renders are presented as actual released interfaces.

## Status

As of November 25, 2026, no reference images have been collected. All research findings in `docs/ANDROID_AUTO_RESEARCH.md` are sourced from publicly available web pages and official Google documentation.
