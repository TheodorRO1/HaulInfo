# Android Auto Visual References

This directory is intended for visual reference images of Android Auto. No images have been collected yet.

## Collection policy

- Only genuine Android Auto screenshots and official Google images are collected.
- Images are sourced from publicly accessible pages and publications.
- For each image: source URL, publication date, Android Auto version (if known), and whether the image shows a released feature or an announced concept are recorded.
- No proprietary application assets, source code, or extracted resources are copied.
- No artificial screenshots are created and presented as genuine Android Auto references.

## Status

As of November 25, 2026, no reference images have been added to this directory. All research findings in `docs/ANDROID_AUTO_RESEARCH.md` are sourced from publicly available web pages and official Google documentation.
